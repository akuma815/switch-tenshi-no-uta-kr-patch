# 천사의 시 한글 패치 적용 안내

## 패치 구성

배포 파일에는 아래 4개 파일이 포함되어 있어야 합니다.

```text
TenshiKR_P.pak
TenshiKR_P.ucas
TenshiKR_P.utoc
TenshiKR_Font_P.pak
```

- `TenshiKR_P.*`: 한글 대사, 비주얼신 자막, UI, 매뉴얼 이미지 패치
- `TenshiKR_Font_P.pak`: 한글 표시용 폰트 패치

원본 게임 파일은 포함되어 있지 않습니다.

## 원본 ROM 정보

이 패치는 아래 원본 기준으로 제작되었습니다.

| 항목 | 내용 |
|---|---|
| 게임 | 천사의 시 |
| 플랫폼 | Nintendo Switch |
| Title ID | `010096F021294000` |
| 패치 방식 | RomFS LayeredFS 방식 |
| 대상 내부 경로 | `Emulator_Tenshinouta\Content\Paks` |

패치 파일에는 원본 게임 데이터가 포함되어 있지 않습니다.  
정상 적용을 위해서는 본인이 소유한 원본 게임 덤프 또는 설치본이 필요합니다.

## 적용 위치

에뮬레이터의 모드 폴더 안에 아래 경로를 만들고, 패치 파일 4개를 복사합니다.

```text
<모드명>\romfs\Emulator_Tenshinouta\Content\Paks\
    TenshiKR_P.pak
    TenshiKR_P.ucas
    TenshiKR_P.utoc
    TenshiKR_Font_P.pak
```

예시:

```text
load\010096F021294000\TenshiKR\romfs\Emulator_Tenshinouta\Content\Paks\
```

## Switch 실기 적용 방법

Switch 실기에서는 Atmosphere의 LayeredFS 경로에 패치 파일을 넣습니다.

SD 카드에 아래 폴더를 만듭니다.

```text
atmosphere\contents\010096F021294000\romfs\Emulator_Tenshinouta\Content\Paks\
```

그 안에 패치 파일 4개를 복사합니다.

```text
atmosphere\contents\010096F021294000\romfs\Emulator_Tenshinouta\Content\Paks\
    TenshiKR_P.pak
    TenshiKR_P.ucas
    TenshiKR_P.utoc
    TenshiKR_Font_P.pak
```

복사 후 게임을 다시 실행하면 패치가 적용됩니다. 이미 게임이 실행 중이었다면 완전히 종료한 뒤 다시 실행하세요.

## 주의사항

- 원본 `Emulator_Tenshinouta-Switch.pak`, `.ucas`, `.utoc` 파일은 삭제하거나 교체하지 마세요.
- 패치 파일은 원본 파일 옆에 추가로 넣는 방식입니다.
- 4개 파일 중 하나라도 빠지면 글자가 깨지거나 패치가 정상 적용되지 않을 수 있습니다.
- 이전 버전의 `TenshiKR_P.*` 파일이 있다면 새 파일로 모두 덮어써 주세요.
- 저장 데이터와는 별개로 동작하지만, 패치 적용 전 저장 데이터를 백업해두는 것을 권장합니다.
- 실기 적용 시 SD 카드의 `atmosphere\contents\010096F021294000` 경로가 맞는지 확인하세요.

## 적용 확인

게임 실행 후 아래 항목을 확인하면 됩니다.

- 메뉴와 게임 선택 화면이 한글로 표시됨
- 대사창의 한글이 정상 표시됨
- 비주얼신 자막이 한글로 표시되고 화면 진행과 싱크가 맞음
- 게임 내 매뉴얼 이미지가 한글로 표시됨

## 문제 해결

### 한글이 네모 또는 빈칸으로 나오는 경우

`TenshiKR_Font_P.pak`가 빠졌거나 경로가 잘못된 경우입니다.  
패치 파일 4개가 모두 같은 `Paks` 폴더에 있는지 확인하세요.

### 대사는 한글인데 일부 화면이 영어로 나오는 경우

`TenshiKR_P.pak`, `TenshiKR_P.ucas`, `TenshiKR_P.utoc` 중 일부가 빠졌을 수 있습니다.  
세 파일을 같은 버전으로 모두 다시 복사하세요.

### 게임이 실행되지 않는 경우

원본 pak 파일을 교체했는지 확인하세요.  
이 패치는 원본 파일을 수정하지 않고, 별도 `_P` 패치 파일을 추가하는 방식으로만 사용해야 합니다.

Switch 실기라면 Title ID 폴더명이 `010096F021294000`인지, 그리고 `romfs` 아래 경로가 정확한지 확인하세요.

### 이전 번역이 계속 보이는 경우

에뮬레이터 모드 폴더에 이전 패치 파일이 남아 있을 수 있습니다.  
기존 `TenshiKR_P.pak`, `TenshiKR_P.ucas`, `TenshiKR_P.utoc`, `TenshiKR_Font_P.pak`를 삭제한 뒤 새 파일 4개를 다시 복사하세요.

## 패치 제거

아래 4개 파일을 모드 폴더에서 삭제하면 패치가 제거됩니다.

```text
TenshiKR_P.pak
TenshiKR_P.ucas
TenshiKR_P.utoc
TenshiKR_Font_P.pak
```

원본 게임 파일은 건드리지 않아도 됩니다.
